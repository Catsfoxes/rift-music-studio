# Rift Music Studio

This is our test music app thingy. 🎵

## First prototype

The first build is a small browser-based music playground. It can:

- Load a local audio file from your device
- Play, pause, and stop the track
- Show the browser's audio controls

This is intentionally small so we can build it up in layers instead of trying to make the whole studio at once.

## Next ideas

- Track/timeline view
- Multiple audio layers
- Volume controls per layer
- Looping
- Tempo/BPM controls
- Simple beat and instrument tools
- Save/load projects
- Eventually, a more powerful instrument and beat-building system
